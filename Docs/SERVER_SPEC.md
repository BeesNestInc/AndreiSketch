# サーバーサイド仕様
- ランタイム: Node.js (Fastify)
- DB接続:
    - DuckDB をメインエンジンとして使用。
    - DuckDBの `postgres` 拡張をロードし、`ATTACH` 文を用いてオンプレミスのPostgreSQLデータベースをマウントする。これにより、データをコピーすることなくライブクエリが可能になる。
- 主要エンドポイント:
    - POST `/api/query`:
        - クライアントからSQLを受け取る。
        - `ATTACH`済みのPostgreSQLデータベースに対し、DuckDBエンジン経由でクエリを実行し、結果をJSONで返す。
        - **注意:** 結果セットに`BigInt`型が含まれる場合、JSONシリアライズ前に文字列に変換する必要がある。
    - POST `/api/execute-js`: (未実装)
        - クライアントからJSコード文字列を受け取る。
        - サーバー側でデータを保持した状態でJSを実行し、結果を返す。
- 依存ライブラリ: `fastify`, `duckdb`, `@formkit/tempo`
- 日付処理: `@formkit/tempo` を使用し、クライアントに返す前に日付・時刻型を `YYYY-MM-DD HH:mm:ss` 形式の文字列にフォーマットする。
- コード哲学:
    - async/await を用いたモダンな非同期処理。
    - DuckDBの `postgres` 拡張を活用し、オンプレDBを「マウント」してライブクエリを実行するアーキテクチャを採用。
